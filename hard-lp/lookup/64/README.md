# lookup64

Синтетический линейный поиск первого совпадения в массиве. В анализируемой функции `lookup_64_unr_full` цикл заменён 64 явными шагами, которые сохраняют проверки границы и флаг первого совпадения.

## Замеры

- OTAWA, экспорт с FFX — ≈ 15 с
- Pathfinder — ≈ 174 с
- Ограничения — 517 → 3920
- WCET (оценка ILP) — 6155 → 5050

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 213,42 с | 1288,03 с |
| SCIP | TL (1800,94 с) | 932,26 с |
| FSCIP | 696,09 с | 1292,73 с |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.

Для серий, затронутых сном компьютера, приведены результаты повторных прогонов.
