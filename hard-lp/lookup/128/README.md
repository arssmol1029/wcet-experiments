# lookup128

Синтетический линейный поиск первого совпадения в массиве. В анализируемой функции `lookup_128_unr_full` цикл заменён 128 явными шагами, которые сохраняют проверки границы и флаг первого совпадения.

## Замеры

- OTAWA, экспорт с FFX — время не подтверждено
- Pathfinder — время не подтверждено
- Ограничения — 1029 → 7879
- WCET (оценка ILP) — 12235 → 10050

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | TL (1800,1 с) | TL (1800,09 с) |
| SCIP | TL (1801,26 с) | TL (1801,28 с) |
| FSCIP | TL (1803,5 с) | TL (1801,56 с) |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.

Для серий, затронутых сном компьютера, приведены результаты повторных прогонов.

Оптимум 10050 доказан отдельно динамическим программированием.
