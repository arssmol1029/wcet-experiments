# lookup128

Синтетический линейный поиск первого совпадения в массиве. В анализируемой функции `lookup_128_unr_full` цикл заменён 128 явными шагами, которые сохраняют проверки границы и флаг первого совпадения.

## Замеры

- OTAWA — 38,03 с
- Pathfinder — 1343,05 с
- Ограничения — 1029 → 7879
- WCET — 12235 → 10050

### Решение ЛП модели, TL 1800 с

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | TL | TL |
| SCIP | TL | TL |
| FSCIP | TL | TL |

## Сопоставление вариантов

Проверка эквивалентности: Версии неэквивалентны: исходная проверяет 16 позиций, развёрнутая — N−1..

Цели моделей приведены в условных единицах по 5 на ARM-инструкцию; корректность ограничений следует оценивать отдельно.

| Вариант | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| До развёртывания | несопоставимо | несопоставимо |
| После развёртывания | несопоставимо | несопоставимо |
