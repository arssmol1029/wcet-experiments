# nginx round-robin 24×8

Фрагмент nginx 1.26.2 выбирает сервер взвешенным round-robin из 24 серверов с состояниями, заданными восемью неизвестными битами. Обход серверов развёрнут, функция встроена в точку входа, а проверки доступности и обновления весов и лидера сохранены; полный FFX проверен на всех 256 входах контракта.

## Замеры

- OTAWA — 50,34 с
- Pathfinder — 1346,63 с
- Ограничения — 937 → 5981
- WCET — 18205 → 15160
