# nginx round-robin 20×8

Фрагмент nginx 1.26.2 выбирает сервер взвешенным round-robin из 20 серверов с состояниями, заданными восемью неизвестными битами. Обход серверов развёрнут, функция встроена в точку входа, а проверки доступности и обновления весов и лидера сохранены; полный FFX проверен на всех 256 входах контракта.

## Замеры

- OTAWA — 38,80 с
- Pathfinder — 1022,34 с
- Ограничения — 783 → 5144
- WCET — 15265 → 12720
