# nginx-roundrobin/18x8: новый профиль

Префикс списка узлов выбран из экспериментальной пары 20×8; сохранено хранилище на 20 элементов, а общая обвязка нормирует восемь входных битов. Сравниваются `reference.c` и `unrolled.c`; `model.lp` — полная модель развёрнутой версии с Pathfinder.

## Результаты моделей

| Версия | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| Циклическая | 14680 | FFX отвергнут |
| Развёрнутая | 14645 | 12365 |

Цели получены HiGHS, SCIP и FSCIP со статусом OPTIMAL; решения перепроверены целочисленной арифметикой по соответствующим исходным LP, после документированного округления при необходимости. Полная модель исходной версии не решалась: одно добавленное FFX-ограничение противоречит допустимым ARM/native трассам.

Развёрнутая модель с Pathfinder, presolve on/default, TL 1750/1800 с, seed 0, один поток или worker: highs — 34.237 с; scip — 42.697 с; fscip — 70.498 с (wall time). SCIP/FSCIP — изолированные сборки без MPI/Ipopt.

Для обеих версий проверены все 256 нормированных входов и базовые LP-строки; для развёрнутой версии все добавленные FFX-строки допускают эти трассы. Условие применимости — корректная привязка ARM/CFG и обоснование обычных FF. Оптимум модели не объявляется безусловным WCET. [Протокол и доказательства](../../../../research/hard-lp-new-profiles-20261120/STATUS.md). Сырые данные VM: `/home/ahunuin/lp_benchmark/build/outputs/hard-lp-nginx-new-20261120-01`.

## Эквивалентность

Исходная и развёрнутая версии совпали по наблюдаемым результатам на проверенных входах: все 256 нормированных входов. Область проверки ограничена этими входами и контрактом профиля.
