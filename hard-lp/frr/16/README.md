# frr-v16-all

Синтетическая адаптация `zebra_nht_rm_update` из FRR с фиксированным входом и 16 копиями записи VRF. Целевые циклы обхода VRF, типов маршрутов и next-hop развёрнуты, а циклы инициализации и `memcpy` используют архивные границы.

## Замеры

- OTAWA, экспорт с FFX — 174,17 с
- Pathfinder — 1844,47 с
- Ограничения — 34523 → 40240
- WCET (оценка ILP) — 1042390 → 1040590

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 11,47 с | — |
| SCIP | 42,83 с | — |
| FSCIP | 44,89 с | — |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.
