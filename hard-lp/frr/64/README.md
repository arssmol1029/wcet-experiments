# frr-v64-all

Синтетическая адаптация `zebra_nht_rm_update` из FRR с фиксированным входом и 64 копиями записи VRF. Целевые циклы обхода VRF, типов маршрутов и next-hop развёрнуты, а циклы инициализации и `memcpy` используют архивные границы.

## Замеры

- OTAWA — 4554,63 с
- Pathfinder — 7904,84 с
- Ограничения — 137893 → 160746
- WCET — 4160370 → 4153125
