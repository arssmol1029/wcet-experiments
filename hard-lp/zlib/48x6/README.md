# zlib/48x6: новый профиль

Циклическая версия реконструирована из экспериментальной развёрнутой адаптации, а не восстановлена из zlib. Таблица хранит 56 кандидатов шаблона; обрабатывается только указанный префикс, match_start пересчитан под размер. Сравниваются `reference.c` и `unrolled.c`; `model.lp` — полная модель развёрнутой версии с Pathfinder.

## Результаты моделей

| Версия | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| Циклическая | 40025 | 39895 |
| Развёрнутая | 19625 | 6680 |

Все цели получены HiGHS, SCIP и FSCIP со статусом OPTIMAL; решения перепроверены целочисленной арифметикой по соответствующим исходным LP, после документированного округления при необходимости.

Развёрнутая модель с Pathfinder, presolve on/default, TL 1750/1800 с, seed 0, один поток или worker: highs — 43.221 с; scip — 99.826 с; fscip — 75.504 с (wall time). SCIP/FSCIP — изолированные сборки без MPI/Ipopt.

Для каждой версии проверены все 5832 классов управления на ARM и native, а также базовые и добавленные строки FFX. Проверка разбиения опирается на корректность компиляции определённого C и привязки ARM/CFG. Обычные FF и модель стоимости рассматриваются отдельно; оптимум ILP не объявляется безусловным WCET. [Протокол и доказательства](../../../../research/hard-lp-new-profiles-20261120/STATUS.md). Сырые данные VM: `/home/ahunuin/lp_benchmark/build/outputs/hard-lp-pg-zlib-20261120-01`.

## Эквивалентность

Исходная и развёрнутая версии совпали по наблюдаемым результатам на проверенных входах: 64 класса и 1000 дополнительных входов. Область проверки ограничена этими входами и контрактом профиля.
