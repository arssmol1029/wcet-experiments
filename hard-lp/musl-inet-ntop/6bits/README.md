# musl inet_ntop, 6 переменных групп

Фрагмент musl 1.2.5 `inet_ntop` ищет самую длинную нулевую последовательность в IPv6-адресе с шестью неизвестными группами 0/1. Форматирование специализировано под контракт, проходы поиска и копирования развёрнуты с сохранением правила выбора при равенстве; полный FFX проверен на всех 64 входах контракта.

## Замеры

- OTAWA — 18,40 с
- Pathfinder — 181,28 с
- Ограничения — 1029 → 4256
- WCET — 8595 → 6355
