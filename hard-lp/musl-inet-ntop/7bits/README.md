# musl inet_ntop, 7 переменных групп

Фрагмент musl 1.2.5 `inet_ntop` ищет самую длинную нулевую последовательность в IPv6-адресе с семью неизвестными группами 0/1. Форматирование специализировано под контракт, проходы поиска и копирования развёрнуты с сохранением правила выбора при равенстве; полный FFX проверен на всех 128 входах контракта.

## Замеры

- OTAWA — 25,02 с
- Pathfinder — 201,51 с
- Ограничения — 1029 → 5480
- WCET — 8610 → 7385
