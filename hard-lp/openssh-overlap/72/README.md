# OpenSSH, 72 шаблона

Адаптация OpenSSH 9.8p1 `match_pattern_list` проверяет 72 фиксированных положительных и отрицательных шаблона на восьмисимвольном входе `a`/`b`. Обход списка и сравнения развёрнуты, набор подстановок ограничен `?`, сохранены накопление положительного совпадения и немедленный выход при отрицательном совпадении; полный FFX проверен на всех 256 входах контракта.

Исходная функция находится в [`match.c`](https://github.com/openssh/openssh-portable/blob/V_9_8_P1/match.c).

## Замеры

- OTAWA — TL 1800 с для полного FFX (базовый экспорт 1,34 с)
- Pathfinder — 935,22 с
- Ограничения — 2395 → 21 175
- WCET — 12 230 → 4185
- Максимум по 256 ARM-трассам — 4120

LP получена прямым переводом 18 780 фактов FFX за 1,97 с. Все факты сопоставлены строкам модели, совпадение со штатным экспортом этого размера не установлено. Стоимость ARM — пять единиц на инструкцию.

### Решение ЛП модели, TL 1800 с

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 162,05 с | 190,52 с |
| SCIP | 348,18 с | 510,50 с |
| FSCIP | 884,25 с | 288,70 с |

Решения трёх решателей проверены; в журнале SCIP есть предупреждение о численных трудностях при решении одной LP. HiGHS и SCIP работали в один поток, FSCIP — с четырьмя работниками, seed 0.
