# OpenSSH, 96 шаблонов

Адаптация OpenSSH 9.8p1 `match_pattern_list` проверяет 96 фиксированных положительных и отрицательных шаблонов на восьмисимвольном входе `a`/`b`. Обход списка и сравнения развёрнуты, набор подстановок ограничен `?`, сохранены накопление положительного совпадения и немедленный выход при отрицательном совпадении, полный FFX проверен на всех 256 входах контракта.

Исходная функция находится в [`match.c`](https://github.com/openssh/openssh-portable/blob/V_9_8_P1/match.c).

## Замеры

- OTAWA — TL 1800 с для полного FFX (базовый экспорт 2,75 с)
- Pathfinder — 1061,88 с
- Ограничения — 3195 → 24 468
- WCET — 16 300 → [5730; 8330]
- Максимум по 256 ARM-трассам — 5365

LP получена прямым переводом 21 273 фактов FFX за 2,04 с. Все факты сопоставлены строкам модели, совпадение со штатным экспортом этого размера не установлено. Интервал задаёт границы оптимума ILP при стоимости пять единиц на ARM-инструкцию.

### Решение ЛП модели, TL 1800 с

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | TL | — |
| SCIP | TL | — |
| FSCIP | TL | — |

`—` означает, что замера нет. Статус HiGHS взят из его журнала, сохранённое решение независимо проверено. HiGHS и SCIP работали в один поток, FSCIP — с четырьмя работниками, seed 0.
