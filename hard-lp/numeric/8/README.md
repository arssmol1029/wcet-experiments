# numeric8

Синтетическая BPF-политика, скомпилированная [ARM JIT Linux 6.6](https://github.com/torvalds/linux/blob/v6.6/arch/arm/net/bpf_jit_32.c). Политика проверяет 8 входных слов, а ассемблерная обвязка подключает сохранённый JIT-образ с ациклическим графом.

## Замеры

- OTAWA, экспорт с FFX — 39,66 с
- Pathfinder — 73,62 с
- Ограничения — 471 → 5603
- WCET (оценка ILP) — 6245 → 4305

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 308 с<br>TL (120,22 с), лимит 120 с | — |
| SCIP | TL (900,74 с)<br>TL (120,7 с), лимит 120 с | — |
| FSCIP | TL (120,73 с) | — |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.
