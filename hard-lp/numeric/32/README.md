# numeric32

Синтетическая BPF-политика, скомпилированная [ARM JIT Linux 6.6](https://github.com/torvalds/linux/blob/v6.6/arch/arm/net/bpf_jit_32.c). Политика проверяет 32 входных слов, а ассемблерная обвязка подключает сохранённый JIT-образ с ациклическим графом.

## Замеры

- OTAWA, экспорт с FFX — —
- Pathfinder — 449,48 с
- Ограничения — 2439 → 30575
- WCET (оценка ILP) — 32405 → [22845–29445]

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | TL (900,3 с) | — |
| SCIP | TL (900,35 с) | — |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.

Интервал после FFX объединяет проверенное допустимое решение и лучшую верхнюю границу решателей.
