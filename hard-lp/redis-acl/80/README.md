# Redis ACL, 80 правил

Адаптация Redis 7.2.5 `ACLSelectorCheckKey` проверяет фиксированный список из 80 шаблонов для ключа из шести символов `a`/`b` и двух битов запроса чтения и вставки. Обход списка и сравнения развёрнуты, сохранены проверка прав и выход при первом совпадении, полный FFX проверен на всех 256 входах контракта.

Исходные функции — [`ACLSelectorCheckKey`](https://github.com/redis/redis/blob/7.2.5/src/acl.c) и [`stringmatchlen`](https://github.com/redis/redis/blob/7.2.5/src/util.c).

## Замеры

- OTAWA — 6403,56 с (продлённый экспорт, лимит 10800 с)
- Pathfinder — 1022,72 с
- Ограничения — 2287 → 22846
- WCET — 11495 → [7305; 7520]
- Максимум по 256 ARM-трассам — 5230

Штатная LP побайтно совпала с прямым переводом FFX, на котором измерены решатели. Значения в квадратных скобках задают интервал оптимума ILP. Стоимость ARM — пять единиц на инструкцию. Часть замеров пересеклась по времени с построением других моделей.

### Решение ЛП модели, TL 1800 с

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | TL | — |
| SCIP | TL | — |
| FSCIP | TL | — |

`—` означает, что замера нет. HiGHS и SCIP работали в один поток, FSCIP — с четырьмя работниками, seed 0.
