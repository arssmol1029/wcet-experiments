# of-match/40: новый профиль

Циклическая версия реконструирована из экспериментальной развёрнутой адаптации, а не восстановлена из исходников Linux. Обрабатываются первые 40 элементов шаблона; исходное хранение таблицы сохранено. Сравниваются `reference.c` и `unrolled.c`; `model.lp` — полная модель развёрнутой версии с Pathfinder.

## Результаты моделей

| Версия | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| Циклическая | 8185 | 8185 |
| Развёрнутая | 4355 | 3805 |

Все цели в таблице получены HiGHS, SCIP и FSCIP со статусом OPTIMAL; сохранённые решения перепроверены целочисленной арифметикой по соответствующим исходным LP, после документированного округления при необходимости. Это цели моделей; полнота обычных FF и FFX исходной версии рассматривается отдельно.

Развёрнутая модель с Pathfinder, presolve on/default, TL 1750/1800 с, seed 0, один поток или worker: HiGHS — 140.504 с, SCIP — 75.963 с, FSCIP — 140.091 с (wall time). SCIP/FSCIP — изолированные сборки без MPI/Ipopt.

Для развёрнутой версии все добавленные FFX-строки проверены на полном домене управляющих классов по машинному шаблону и точной динамической программе; это доказательство зависит от семантики ARM и привязки CFG. [Протокол и доказательства](../../../../research/hard-lp-new-profiles-20261120/STATUS.md). Сырые данные VM: `/home/ahunuin/lp_benchmark/build/outputs/hard-lp-new-profiles-20261120-03`.

## Эквивалентность

Исходная и развёрнутая версии совпали по наблюдаемым результатам на проверенных входах: 1042–1122 подготовленных входа на пару; дополнительно проверена структура ветвей. Область проверки ограничена этими входами и контрактом профиля.
