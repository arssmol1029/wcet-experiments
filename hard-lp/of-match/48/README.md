# of-match-48-direct

Адаптация [`__of_match_node` из Linux Device Tree](https://github.com/torvalds/linux/blob/v6.12/drivers/of/base.c). Обход 48 записей развёрнут, а проверка лучшего балла перенесена внутрь ветвей трёх фиксированных рангов с сохранением первого совпадения при равенстве.

## Замеры

- OTAWA, экспорт с FFX — 22,25 с
- Pathfinder — 385,11 с
- Ограничения — 875 → 6773
- WCET (оценка ILP) — 5195 → 4535

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 42,86 с | — |
| SCIP | 57,78 с | — |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.
