# getopt-alias-64

Адаптация [`process_long_option` из glibc 2.40](https://github.com/bminor/glibc/blob/glibc-2.40/posix/getopt.c). Проверки 64 имён развёрнуты для фиксированного односимвольного сокращения, при этом сохранены выбор первого совпадения и проверка неоднозначности.

## Замеры

- OTAWA, экспорт с FFX — 2,05 с
- Pathfinder — 85,36 с
- Ограничения — 395 → 1820
- WCET (оценка ILP) — 4890 → 3830

### Решение с Pathfinder

| Решатель | Presolve on | Presolve off |
|---|---|---|
| HiGHS | 53,73 с | — |
| SCIP | 0,35 с | — |

Время процесса в секундах. TL — достигнут лимит времени. Тире означает отсутствие замера.
