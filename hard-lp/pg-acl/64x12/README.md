# pg-acl/64x12: новый профиль

Циклическая версия реконструирована из экспериментальной развёрнутой адаптации, а не восстановлена из PostgreSQL. Сохранены первые два безусловных и последующие правила префикса; вход — 12 слов. Сравниваются `reference.c` и `unrolled.c`; `model.lp` — полная модель развёрнутой версии с Pathfinder.

## Результаты моделей

| Версия | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| Циклическая | 11140 | 11140 |
| Развёрнутая | 5710 | 2610 |

Все цели получены HiGHS, SCIP и FSCIP со статусом OPTIMAL; решения перепроверены целочисленной арифметикой по соответствующим исходным LP, после документированного округления при необходимости.

Развёрнутая модель с Pathfinder, presolve on/default, TL 1750/1800 с, seed 0, один поток или worker: highs — 42.468 с; scip — 96.284 с; fscip — 91.790 с (wall time). SCIP/FSCIP — изолированные сборки без MPI/Ipopt.

Для каждой версии проверены все 4096 классов управления на ARM и native, а также базовые и добавленные строки FFX. Проверка разбиения опирается на корректность компиляции определённого C и привязки ARM/CFG. Обычные FF и модель стоимости рассматриваются отдельно; оптимум ILP не объявляется безусловным WCET. [Протокол и доказательства](../../../../research/hard-lp-new-profiles-20261120/STATUS.md). Сырые данные VM: `/home/ahunuin/lp_benchmark/build/outputs/hard-lp-pg-zlib-20261120-01`.

## Эквивалентность

Исходная и развёрнутая версии совпали по наблюдаемым результатам на проверенных входах: все 4096 булевых классов входов. Область проверки ограничена этими входами и контрактом профиля.
