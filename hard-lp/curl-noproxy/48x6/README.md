# curl NO_PROXY 48×6

Фрагмент curl 8.10.1 `Curl_check_noproxy` проверяет фиксированный список из 48 шаблонов для имени с шестью неизвестными двоичными символами. Разбор фиксированного списка и сравнения развёрнуты, для контракта сохранены точные и суффиксные совпадения и первый выход при совпадении; полный FFX проверен на всех 64 входах контракта.

## Замеры

- OTAWA — 782,17 с
- Pathfinder — 257,91 с
- Ограничения — 1799 → 9820
- WCET — 8755 → 2980
