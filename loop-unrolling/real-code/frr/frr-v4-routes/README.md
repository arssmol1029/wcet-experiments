# frr-v4-routes

## Сопоставление вариантов

На 128 подготовленных начальных состояниях варианты совпали по наблюдаемому состоянию; проверка выборочная. Значения ниже — цели моделей, 5 условных единиц на ARM-инструкцию.

| Вариант | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| До развёртывания | 342675 | Некорректное ограничение |
| После развёртывания | 333670 | Некорректное ограничение |

При обходе четырёх виртуальных таблиц программа несколько раз копирует данные: каждый вызов `memcpy` перебирает 2568 байт. При переносе ограничения в модель повторы цикла копирования сложили за все вызовы и ограничили общую сумму числом 3264. Но четыре допустимых вызова дают 10268 повторов цикла, поэтому модель исключает это исполнение.
