# budget-unrolled-32

## Сопоставление вариантов

Для размера 32 сравниваются исходная и развёрнутая версии. Значения — цели моделей в условных единицах, 5 на ARM-инструкцию.

| Вариант | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| До развёртывания | 38675 | нет корректного результата |
| После развёртывания | 37845 | 33545 |

Эквивалентность C-версий для определённых входов установлена структурной индукцией; для размеров 16, 32 и 64 дополнительно проверены 1030 наборов на пару.

Pathfinder добавил ограничение, запрещающее выполнение средней операции после пропуска тяжёлой. Однако при бюджете 1 тяжёлая операция пропускается, а средняя расходует оставшуюся единицу. Это допустимое исполнение, которое ограничение исключает.
