# threshold-rolled-16

## Сопоставление вариантов

Для размера 16 сравниваются исходная и развёрнутая версии. Значения — цели моделей в условных единицах, 5 на ARM-инструкцию.

| Вариант | Без Pathfinder | С Pathfinder |
|---|---:|---:|
| До развёртывания | 14550 | нет корректного результата |
| После развёртывания | 14200 | 14200 |

Эквивалентность C-версий для определённых входов установлена структурной индукцией; для размеров 16, 32 и 64 дополнительно проверены 1030 наборов на пару.
